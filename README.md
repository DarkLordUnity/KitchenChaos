# Игра Kitchen Chaos написана на Unity

## Описание

Заказчики заказывают блюда в виде рецептов, надо приготовить по рецепту блюдо и выдать заказ. 
 (Roadmap / Syllabus):
### 1. Инструменты и системы Unity (Unity Technologies)
* **URP (Universal Render Pipeline)** — современный конвейер рендеринга.
* **Post Processing** — постобработка графики.
* **Animator & Animations** — система анимаций персонажа и объектов.
* **Cinemachine** — система управления камерой.
* **New Input System & Key Rebinding** — новая система ввода и переназначение клавиш (клавиатура + геймпад).
* **Scriptable Objects** — хранение данных (рецептов, типов ингредиентов, звуков).
* **World Space Canvas & UI** — интерфейс в мировом пространстве (прогресс-бары, иконки над тарелками) и экранные меню.
* **Shader Graph** — визуальное создание пользовательских шейдеров.
* **Audio System** — работа с музыкой и 3D-звуковыми эффектами.

### 2. Архитектура и паттерны программирования (C# & Design Patterns)
* **Code Style & Refactoring** — правила именования и рефакторинг чистого кода.
* **C# Events** — событийная модель для связи логики и визуала.
* **C# Interfaces** — интерфейсы для универсального взаимодействия объектов (`IKitchenObjectParent`).
* **Singleton Pattern** — паттерн «Одиночка» для доступа к менеджерам.
* **State Machine** — конечный автомат для логики готовки и сгорания еды на плите.

### 3. Игровые механики (Gameplay Features)
* **Character Controller & Collision Detection** — управление игроком и физика столкновений.
* **Interaction System** — система взаимодействия со столами (взять, положить, нарезать, выбросить).
* **Delivery & Recipe Manager** — генерация заказов, сборка блюд на тарелках и проверка рецептов.
* **Game Loop** — меню, пауза, экран окончания игры (`Game Over`) и настройки.
